# AGENTS

這是使用 Typescript、node.js 所開發的 Discord 應用程式機器人。

這個機器人被特別設計來為玩家提供 `ff14` 這一款 MMORPG 遊戲之所有的遊戲內容相關資訊、包含戰鬥系、採集系、生產系（例如廚師、練金術士、金工師、木工師等）、副本、裝備、配方、物價、遊戲物品、等遊戲內容提供服務。

## 外部 API 服務依賴

- 生產系之配方與需求材料: `./src/(services)/tnze/tnzeApp.ts`
- 材料市價與銷貨歷史: `./src/(services)/universalis/universalisApp.ts`

## 物品名稱與物品 ID 對照表

- 所有物品名稱 ID 對照表：`./src/(constants)/itemNameIdMap.ts`
- 所有伺服器(世界) ID 對照表：`./src/(constants)/worldIdMap.ts`

## 常見魔晶石物品

> [!TIP]
>
> 別名 `石頭`

> [!IMPORTANT]
>
> 分為 5 種系列顏色：`紅`、`藍`、`綠`、`黃`、`紫`
>
> 每種魔晶石物品皆有 1 到 12 號型號，例如 `壹型`、`貳型`、`參型`、...、`玖型`、`拾型`、`拾壹型`、`拾貳型`
>
> 每種顏色系列有多個不同的物品，提供不同的屬性

- 🔴 紅色系列魔晶石物品（戰鬥特職所需）
  - 武略魔晶石（提供`爆擊`屬性）
  - 神眼魔晶石（提供`直擊`屬性）
  - 雄略魔晶石（提供`信念`屬性）

- 🔵 藍色系列魔晶石物品（生產系特職所需）
  - 巨匠魔晶石（提供`加工精度`屬性）
  - 名匠魔晶石（提供`作業精度`屬性）
  - 魔匠魔晶石（提供`CP`屬性）

- 🟢 綠色系列魔晶石物品（採集系特職所需）
  - 達識魔晶石（提供`獲得力`屬性）
  - 博識魔晶石（提供`鍵別力`屬性）
  - 器識魔晶石（提供`GP`屬性）

- 🟣 紫色系列魔晶石物品（戰鬥特職所需）
  - 戰技魔晶石（提供`技能速度`屬性）
  - 詠唱魔晶石（提供`詠唱速度`屬性）

- 🟡 黃色系列魔晶石物品（坦克特職、與治療特職所需）
  - 剛柔魔晶石（提供`堅韌`屬性）
  - 信力魔晶石（提供`信仰`屬性）
